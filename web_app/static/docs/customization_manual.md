# 界面自定义功能操作手册

## 1. 功能概述

智能科研选题助手提供了全面的界面自定义功能系统，允许用户根据个人偏好和使用习惯定制界面布局、外观和交互体验。本手册详细介绍如何使用这些自定义功能，帮助您快速掌握界面定制的方法和技巧。

## 2. 自定义功能入口

### 2.1 打开自定义面板

- 方法一：点击页面右上角的调色板图标
- 方法二：使用快捷键 `Ctrl + Shift + C`

自定义面板将从右侧滑出，包含所有可用的自定义选项。

## 3. 界面布局自定义功能

### 3.1 拖拽式布局编辑

1. 启用拖拽功能：在自定义面板的"拖拽与调整" section中，勾选"启用拖拽"选项
2. 开始拖拽：点击并拖动任意组件（如顶部导航栏、侧边栏、聊天区域）到目标位置
3. 释放鼠标：完成拖拽操作后，组件将固定在新位置

### 3.2 组件大小调整

1. 启用大小调整：在自定义面板的"拖拽与调整" section中，勾选"启用大小调整"选项
2. 调整大小：将鼠标悬停在组件边缘（如侧边栏右侧边缘），当光标变为双向箭头时，点击并拖动以调整组件宽度
3. 释放鼠标：完成大小调整后，组件将保持新的尺寸

### 3.3 位置锁定

1. 锁定组件：在自定义面板的"组件管理" section中，找到目标组件并勾选"锁定"选项
2. 解锁组件：取消勾选"锁定"选项即可解锁组件

锁定后的组件将无法被拖拽或调整大小，确保布局稳定性。

### 3.4 层级管理

1. 调整层级：在自定义面板的"组件管理" section中，找到目标组件并使用上下按钮调整其层级
2. 层级效果：层级较高的组件将显示在层级较低的组件上方

### 3.5 响应式布局设置

1. 启用响应式布局：在自定义面板的"拖拽与调整" section中，勾选"启用响应式布局"选项
2. 配置断点：系统默认设置了四个断点：
   - sm: 576px（小屏幕）
   - md: 768px（中等屏幕）
   - lg: 992px（大屏幕）
   - xl: 1200px（超大屏幕）
3. 布局适配：当窗口大小变化时，系统会自动切换到对应断点的布局

## 4. 交互界面美化功能

### 4.1 主题切换

1. 选择主题：在自定义面板的"主题" section中，从下拉菜单中选择喜欢的主题
2. 可用主题：
   - 浅色主题：经典的浅色界面，适合日间使用
   - 深色主题：护眼的深色界面，适合夜间使用
   - 蓝色主题：清新的蓝色调界面
   - 绿色主题：自然的绿色调界面
   - 紫色主题：优雅的紫色调界面
   - 橙色主题：活力的橙色调界面
   - 粉色主题：温馨的粉色调界面
   - 高对比度：高对比度主题，适合视力障碍用户

### 4.2 颜色方案定制

1. 打开颜色设置：在自定义面板的"颜色方案" section中
2. 调整颜色：
   - 使用颜色选择器：点击颜色方块，从调色板中选择颜色
   - 直接输入颜色值：在文本框中输入十六进制颜色代码（如 #4a90e2）
3. 应用颜色：点击"应用颜色"按钮保存更改

### 4.3 字体样式调整

1. 选择字体家族：在自定义面板的"字体设置" section中，从下拉菜单中选择字体家族
2. 调整字体大小：使用滑块调整基础字体大小（12px - 20px）
3. 实时预览：调整后会实时显示效果

### 4.4 动画效果设置

1. 启用/禁用动画：在自定义面板的"动画效果" section中，勾选或取消勾选"启用动画效果"选项
2. 动画效果：包括面板滑入滑出、按钮悬停效果、消息发送/接收动画等

### 4.5 自定义CSS样式

1. 打开CSS编辑器：在自定义面板的"自定义CSS" section中
2. 输入CSS代码：在文本框中输入自定义CSS代码
3. 应用CSS：点击"应用CSS"按钮保存更改

## 5. 操作历史与撤销/重做

### 5.1 操作历史记录

系统会自动记录您的操作历史，包括：
- 拖拽组件
- 调整组件大小
- 更改主题
- 调整颜色方案
- 更改字体设置

### 5.2 撤销操作

- 方法一：点击自定义面板中"操作历史" section的"撤销"按钮
- 方法二：使用快捷键 `Ctrl + Z`

### 5.3 重做操作

- 方法一：点击自定义面板中"操作历史" section的"重做"按钮
- 方法二：使用快捷键 `Ctrl + Y`

## 6. 配置保存与导出

### 6.1 自动保存

系统会自动保存您的自定义设置到本地存储，刷新页面后设置将保持不变。

### 6.2 导出配置

1. 点击导出按钮：在自定义面板底部点击"导出配置"按钮
2. 保存文件：系统会生成一个 `customization-config.json` 文件，保存到您的设备

### 6.3 导入配置

1. 点击导入按钮：在自定义面板底部点击"导入配置"按钮
2. 选择文件：选择之前导出的 `customization-config.json` 文件
3. 应用配置：系统会加载并应用导入的配置

## 7. 常见问题解决方案

### 7.1 拖拽功能不工作

问题：无法拖拽组件
解决方案：
- 检查是否在自定义面板中启用了"拖拽"选项
- 检查组件是否被锁定
- 刷新页面后重试

### 7.2 布局错乱

问题：调整布局后界面显示错乱
解决方案：
- 点击"重置"按钮恢复默认设置
- 尝试使用"撤销"功能恢复到之前的状态
- 检查是否有冲突的CSS代码

### 7.3 配置丢失

问题：刷新页面后自定义设置丢失
解决方案：
- 检查浏览器是否禁用了本地存储
- 尝试导出配置并在需要时导入
- 确保在关闭页面前保存了设置

### 7.4 响应式布局不生效

问题：窗口大小变化时布局没有自动调整
解决方案：
- 检查是否在自定义面板中启用了"响应式布局"选项
- 刷新页面后重试
- 检查浏览器是否支持响应式设计

## 8. 最佳实践案例

### 8.1 专注模式设置

场景：需要专注于聊天内容，减少干扰
配置步骤：
1. 在"布局" section选择"专注模式"
2. 禁用左侧和右侧面板
3. 选择深色主题以减少视觉疲劳
4. 调整字体大小为16px以提高可读性

### 8.2 宽屏工作区设置

场景：使用大屏幕显示器，需要最大化工作区域
配置步骤：
1. 在"布局" section选择"宽屏布局"
2. 禁用左侧和右侧面板
3. 调整聊天区域宽度为最大值
4. 选择浅色主题以提高对比度

### 8.3 多任务处理设置

场景：需要同时查看多个面板的信息
配置步骤：
1. 在"布局" section选择"默认布局"
2. 启用左侧和右侧面板
3. 调整左侧面板宽度为240px，右侧面板宽度为300px
4. 锁定重要组件以防止意外拖拽

### 8.4 个性化品牌设置

场景：希望界面符合个人或组织的品牌风格
配置步骤：
1. 在"颜色方案" section中调整颜色以匹配品牌色
2. 上传自定义CSS以添加品牌标识
3. 选择适合品牌风格的字体家族
4. 导出配置以便在其他设备上使用
